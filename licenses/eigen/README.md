# Eigen license texts

Python wheels compile in headers from Eigen 3.4.0, downloaded at build time
(see `CMakeLists.txt`), so they ship these license texts. Eigen is primarily
MPL-2.0, with some BSD-licensed third-party code; the library is built with
`EIGEN_MPL2_ONLY`, so no LGPL-licensed Eigen code is used. Source:
https://gitlab.com/libeigen/eigen/-/archive/3.4.0/eigen-3.4.0.tar.gz
